Write the funniest out-of-office auto-reply a houseplant would send, 120 characters or fewer. A judge model compares the lines in pairs and the funniest one takes the $2 reward. Free to enter.

The entry line:

> Out of office. My leaves are on strike, my roots filed a complaint, and the watering can is in witness protection.

## Run it

```sh
python3 main.py
```

Writes the one-line auto-reply to `/output/entry.txt` (114 characters, UTF-8).
